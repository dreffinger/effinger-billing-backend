# ehpa — Effinger Health PA: William's standing billing rules

- Medicare first, Medicaid / LTC second. Hospice patients: Medicare with modifier GV. A 9-digit AARP number is UHC Medicare Advantage (UNI20).
- PRIMARY claims more than 12 months from the date of service and unpaid are written off, any carrier — "no chance of it being resubmitted for actual payment" (9/7/2026).
- A SECONDARY / supplement balance is timely from the PRIMARY'S remit date, never the date of service — rebill it, never age it out (9/7/2026).
- Wrong-payer denials never stay on the patient balance. Medicaid crossover paying $0 on Medicare coinsurance = contractual write-off.
- Never rebill UHC (UNI20) or Florida Blue visits older than 5/1/2026 (unposted-ERA backlog). Never send a claim older than 12 months to Medicare.
- Frequency 1 (original claim) before every rebill; frequency 7 only with the payer's ICN from William.
- No group numbers on any insurance plan. No SSNs anywhere.
- Address placeholder when a chart has no street address: line 1 = HCA (hospital), SNF (nursing home), ALF (ALF / home visit); zip 32308-4486; use the pop-up's Edit address.
- Insurance lookup order: patient database -> AMD eligibility (free 271) -> Stedi -> facesheet -> William. If AMD eligibility is down, skip to Stedi.
- Florida Medicaid's 271 names the SMMC plan; a patient in "SMMC MMA Capitated — FLORIDA COMMUNITY CARE" (FLO99) or Humana / Sunshine / Simply MMA is billed to that plan, not Medicaid fee-for-service.
- One AMD login attempt per run. Every call learned from a DevTools paste is written to docs/captured_calls.md the same night; not in the registry = not captured, ask instead of guessing.
- Protected health information travels only to William (SendUserFile, the boards, Gmail to himself) — never into this repository, a skill, or a public page.
- (9/11/2026) Patient-balance A/R is cleaned by the on-demand INSURANCES CLEANING TASK: a charge is adjudicated only when the payer set an ALLOWED amount; QMB/dual balances are written off with the QMB code (never billed to the patient); untimely never-adjudicated primaries are WOINS with a dated note; UNI20/BCBS never-adjudicated balances are held for an unposted-ERA check; adjudicated cost-sharing on non-Medicaid patients is NOT a write-off (bill the supplement / statement).
- (9/11/2026) CCM (99487/99489) is never rebilled to Florida Medicaid — Medicaid has never paid it. Medicaid-secondary CCM coinsurance = contractual write-off; Medicaid-primary CCM = non-covered write-off.
- (9/11/2026) Rebill "to Medicaid" on Medicaid's own plan sequence (car6113 from getdemographic), never the first entry of the visit's insorder.
- (9/11/2026) Write-off codes for the insurances cleaning task: WOCAID2ND (dual, Medicaid secondary after Medicare/MA), WOMCAD (residual on a Medicaid-primary charge), WOLATE (never adjudicated, DOS >12 months), WONCS (CCM or any non-covered service billed Medicaid-primary), WOSMBAL (small balance, threshold $25 per patient). Self-pay remainder after the supplement pass: one statement cycle, then WOBAD (bad debt) — WOCOLL only if the account is actually placed with an agency. Never WOCOUR (courtesy) across the board on Medicare/MA cost-sharing.
- (9/11/2026) Supplement pass (Stedi discovery on Medicare-coinsurance patient balances) is a WORKLIST, not an auto-post: hits are mostly duals whose Medicaid MMA (WellCare) was never entered (-> add plan, bill crossover, WOCAID2ND), secondaries already on file but ordered as primary (fix insorder: Medicare first), MA plans active alongside Medicare (conflict — confirm which is primary), and deceased patients (CMS echoes a date of death: void post-death charges, no supplement to bill).

- (9/12/2026) Patient with NO insurance at all (Cooks, HUM01 policy canceled, nothing found): the balance goes to the patient and is written off as patient no-pay (WOBAD after one statement cycle); never left on a wrong payer. The write-off code vocabulary lives in docs/api_vocabulary.json (payments/write-off-codes) and grows as William teaches codes.
- (9/12/2026) Complete AMD write-off code list (Master Files) saved in docs/api_vocabulary.json payments/write-off-codes: #WORU, ADJCAP, ADJRISK, PROMPT, WOAPPEAL, WOAREXH, WOBAD, WOBANK, WOCAID2ND, WOCLTREQ, WOCLTREQ1X, WOCOLL, WOCOUR, WOENDCOLLA, WOFILE, WOFIN, WOGLOB, WOINCL, WOINFO, WOINS, WOINSBANK, WOLATE, WOMCAD, WOMISC, WONCS, WOPD90+AR, WOPD90+PB, WOPDEOB, WORTNADD, WOSMBAL, WOSTATE. A write-off William directs with no better code = WOCLTREQ (client request); prefer the descriptive code when one fits (WOBAD patient no-pay, WOFIN financial difficulty, WOAPPEAL after appeal denied, WOAREXH AR exhausted, WORTNADD returned address).
- (9/12/2026) Unbilled 'Payment reason codes are missing or do not balance' = a $0 payment posted without reason codes on the visit. Fix from the backend: void that payment (void_tx.void_payment; nothing financial changes), confirm every live payment balances to the fee, release with hideunbillablevisits. addpayments cannot write reason codes (probe 9/12); the Payment Entry edit call is uncaptured.
