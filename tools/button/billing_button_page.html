Settings

Inside claude.ai nothing needs to be set up. This page reaches GitHub through your GitHub connector, as you; claude.ai asks once whether to allow it. The token below is only for a copy of this page opened outside claude.ai: a fine-grained personal access token for this one repository, kept in this browser only and never sent anywhere but api.github.com.

The AdvancedMD password and the Stedi key are not entered here. This page never holds them. They go into the repository's locked secrets, where the run on GitHub reads them: Settings → Secrets and variables → Actions → New repository secret → AMD_PSW (the POI0712 password, required) and STEDI_API_KEY (optional). The desktop app has its own Settings with all three fields, because it runs the engine on your PC.

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → effinger-billing-backend.
  3. Permissions: Actions: Read and write, Contents: Read (Metadata is added on its own).
  4. Paste it above and press Save. Press Test; it should answer with your GitHub login.

How it works

The button sends a workflow_dispatch to .github/workflows/billing-button.yml. GitHub starts a fresh machine, checks out main, builds the same workspace the routines use, logs in to AdvancedMD once with the password stored in the repository's secrets, and runs tools/button/run_all.py. That script chains the helpers in this repository in the standing order, dry first and then live when you chose Live, and writes reports/button/<stamp>.json back to the repository; this page reads it. No permission classifier sits in that path. One run at a time: a second press while a run is going waits in line.

on its own
Every two hours at :17 on the even UTC hours except 06:17 (the columns profile) and at 04:05 UTC (the nightly cascade profile), so a scheduled run never shares an hour with the Claude routines, which own the odd hours and 05:30 to 06:30 UTC. A live run, pressed or scheduled, also refuses to start while a Claude routine is due within 25 minutes, and runs a dry pass first when none ran that day. Scheduled runs are dry until the repository variable BUTTON_SCHEDULE_MODE is set to live; BUTTON_SCHEDULE_ENABLED=false stops them. When you go live here, pause the Claude 2-hourly routine so two writers never post the same check.
secrets
Repository → Settings → Secrets and variables → Actions: AMD_PSW (required) and STEDI_API_KEY (optional; without it the cascade and the sweep are skipped).
this PC
The desktop app (Releases → ehpa-billing-button-setup.exe) runs the same engine on your computer with the password typed into its settings, and the Run button on every billing page can open it (ehpa-billing://run).
what it cannot do
A chart fix after a Stedi answer, a dx cascade on a named chart, a hand-post of an unmatched line - those need a judgement and are listed under "Waiting on William or a chat session" in the report.
privacy
The report carries chart ids, visit ids, check ids and dollars only; the privacy gate checks it before it is committed. Helper logs are scrubbed and kept 14 days as a workflow artifact.
