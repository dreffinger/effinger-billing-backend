## The cascade (record every step as a `checks[]` entry: ok / no / na / human)
0. **Facesheet first, when there is one** (Drive folders, board drops, Pam's emails). A PCC admission record settles most of this without a lookup: "Medicaid Only-No Medicare Benefits: Yes" + "Medicare Coverage: No coverage" → **skip the MBI lookup** (no ERR 72 noise, no spend); "Primary Payer" + "Ins. Company" name the plan and the Medicaid # is the member id for SMMC plans; "Second Payer: Patient Liability" is the facility share-of-cost, not a physician payer; the Clinical Resident Profile **CENSUS block** lists the payer on every room-move line — a free, continuous payer history that answers "which plan on that DOS" (pat17469541: MCD Sunshine on every line since 11/23/2023).
1. **AMD chart** — plans + open charges (`txh.fetch`, getdemographic). Note MBI, MA numbers, SSN (last 4 only in notes).
2. **AMD's free 271** on every plan (`amd.check_eligibility(insplan_id)` / `elig_amd.py <pid> --all`, see the AMD API reference) — answers for TODAY and costs nothing; ACTIVE here settles the current plan. **Remits already in AMD** — CO24 = an Advantage plan is responsible; COB9 = hospice; PR27 = coverage terminated; CO16/N382 = bad ID; 'entity not found' = wrong payer.
3. **Stedi MBI lookup** (`stedi.mbi` / `window.mbi`, DOS = the denied date of service) — skip when step 0 says Medicaid-only. Returns the MBI AND the whole Medicare picture for that DOS: Part A/B dates, Medicare Advantage plan (codes U/R with entity name + coordination-of-benefits dates → bill that MA payer), Part D (R/OT = drug plan only → original Medicare), QMB/Medicaid, SNF stays (X), hospice (service type 45), and `planDateInformation.dateOfDeath`. Never use the MBI lookup to "correct" a commercial plan's member id (9/10: it briefly wrote MBIs onto two BCBS plans — reverted).
4. **Payer eligibility** (`stedi.elig` / `window.elig`) on every plan number you hold, with the real DOS — confirms active/inactive and plan dates, subject to the error taxonomy above (a commercial 271 listing the subscriber's own name, riders like "BLUE VIEW VISION" or "NO OTHER INSURANCE" as other/U-R entities is simply ACTIVE — only a name that maps to a real health payer is a wrong-payer signal).
5. **Insurance discovery** (`stedi.disc` / `window.disc`, $1.50) when nothing above names a payer — finds active commercial/MA/Medicaid coverage by name+DOB. 'Not enrolled with DISCOVERY' errors mean the DISCOVERY enrollment is still provisioning; retry later.
6. Only then → **human**: add a `human` trail row saying exactly what William should look up (SPOT / TMH / facility), put the row on his turn.

## Then fix AMD (standing rules)
- Add/fix plans with `add_ins.add` / `ins_update.update` (carrier can be changed in place; no group numbers). End-date dead plans the day before the first denied DOS; set the new plan's begin date from the Stedi/census dates.
- Rebill: `rebill_patient_year.run(pid, order, days)` or `move_to_ins.move(cid, seq)` per visit — freq-1 first. **Filter by DOS and carrier** so you never re-send an unrelated backlog (the 9/6 Blanco lesson: only the denied window). CO24 lines: `co24_restore.run(pid, seq, first, last)`.
- Medicare first, Medicaid/LTC second; hospice → Medicare + GV; 9-digit AARP = UHC MA; >12 months old → write off (`manual_post.post(..., 'WOINS', note=...)`) — but a SECONDARY/supplement balance is timely from the primary's remit date, never from the DOS.
- Timely filing on old dates: when the found plan is right but the DOS is well past its filing window (Sunshine on 2025 dates, say), still rebill freq-1 and let the payer answer — a CO-29 comes back to William as a denials-list decision, never a quiet write-off.
- Date of death on the Medicare record → write off any DOS after it and flag William to confirm/void.
- BCBS plans from the facesheets William sent 9/14 (Collins Miranda's BC Blue Options PPO among them) — his rule: INACTIVE at the DOS with the correct member id → move the balance to patient responsibility as uninsured, then write it off as no-pay bad patient debt (self-pay no-pay; bad-debt code from the 9/11 write-off list unless he says agency placement).
